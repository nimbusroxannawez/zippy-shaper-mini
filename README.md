# zippy-shaper-mini

Haskell · Android · Deno

日常脚本的集中地

## 用法

```bash
cat data.txt | python main.py
```

输出：

```

---

```

## 安装

```bash
git clone https://github.com/USER/zippy-shaper-mini.git
cd zippy-shaper-mini
pip install -r requirements.txt
```
